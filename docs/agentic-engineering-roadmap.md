# Predictable agentic-engineering roadmap

This file persists the tranche definitions so implementation intent does not
depend on conversation history.

## Tranche A — enforceable execution boundary

Implemented: risk and task envelopes, signed external authority, runtime
attestation, credential brokering, task lifecycle, checkpoints, completion
evidence, and fail-closed unattended preflight.

## Tranche B — adversarial security certification

Implemented: deterministic attack corpus, runtime command policy, policy and
enforcement-source binding, live attack reprobes, expiry, and mandatory
certification for unattended execution.

## Tranche C — empirical productivity evidence

Implemented: matched baseline/agentic observations, accepted
production-surviving outcomes, attention and cycle-time speedups, rework,
project-local evidence hashes, live report recomputation, minimum sample size,
and conservative confidence-bound evaluation of the 8x hypothesis.

## Tranche D — evidence-driven progressive autonomy

Implemented: attended, supervised, and unattended modes; risk ceilings;
one-level promotion; exact human-signed promotion capabilities; live
productivity and security prerequisites; integrity-chained state; and automatic
regression when evidence, configuration, or certification changes.

The governing invariant is asymmetric: expanding authority requires fresh
external approval and evidence, while reducing authority may happen
automatically.
