shortlink — Design Mockups (sprint 1)

One mockup per UI-bearing story. Only E4-S1 renders a screen this sprint — E4-S3 is an accessibility audit of the same page, not a separate one, and every other story is API-only (layer: backend or infra).

  • E4-S1 — Console (list your links)
    Story: list the signed-in member's own links, newest first, paginated, with a per-link delete action (E5-S1's endpoint) and an empty state.
    Endpoints: GET /links, DELETE /links/{code} (via the Next.js Route Handlers at /api/links and /api/links/{code} — see api-contracts.md).
    Audited for WCAG 2.2 AA by E4-S3 (keyboard operability, contrast, zero axe violations) against this same page.
