## User Story
As anyone holding a short code, I want to open it and land on the target URL, so that the short link works like the long URL it replaced.

## Business Value
The short code a member shares actually takes the recipient to the intended destination, which is the core value the whole product delivers.

## Description
GET /{code} looks up the code and, when it exists and is not deleted, returns HTTP 302 with Location set to the stored target. The handler never fetches the target itself.

## Scope
**In:** GET /{code} for an existing, not-deleted code returns 302 with Location; GET /{code} for a code that was never issued returns 404
**Out:** Redirect for a deleted code (owned by E5-S1's delete acceptance); Click counts or analytics on redirect (SG-4)

## Acceptance Criteria
- **E3-S1-AC1** — *Given* an existing code, *when* requesting `/{code}`, *then* the response is 302 with `Location` set to the target URL.
- **E3-S1-AC2** — *Given* a code that was never issued, *when* requesting `/{code}`, *then* the response is 404.
- **E3-S1-AC3** — *Given* the redirect handler, *when* it resolves a code to a target URL, *then* it returns the Location header to the caller without itself following or fetching the target URL.
