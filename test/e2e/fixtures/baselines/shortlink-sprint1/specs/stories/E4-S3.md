## User Story
As a member using assistive technology, I want the console list page to be accessible, so that I can view and manage my links without a mouse or with a screen reader.

## Business Value
Members using assistive technology can operate the console as fully as any other member.

## Description
The console list page (rendered by E4-S1) is scanned with an automated WCAG 2.2 AA checker, is fully keyboard-operable, and meets minimum color-contrast requirements.

## Scope
**In:** Automated WCAG 2.2 AA scan of the console list page; Full keyboard operability of pagination and per-link actions; Minimum color-contrast compliance
**Out:** Accessibility of pages outside the console list (sign-in/register forms are covered only if reused by this page)

## Acceptance Criteria
- **E4-S3-AC1** — *Given* the rendered console list page, *when* it is scanned with an automated WCAG 2.2 AA checker (e.g. axe), *then* zero level-A or level-AA violations are reported.
- **E4-S3-AC2** — *Given* the console list page, *when* operated with keyboard only, no mouse, *then* every interactive element (pagination, delete action) is reachable and operable in a visible focus order.
- **E4-S3-AC3** — *Given* the console list page, *when* its text and interactive elements are measured for contrast, *then* every element meets the WCAG 2.2 AA minimum contrast ratio.
