## User Story
As a signed-in member, I want to delete one of my own links, so that its code stops working and I control what stays shareable.

## Business Value
A member can revoke a link they no longer want live, and be certain nobody else can reuse the freed-up code.

## Description
DELETE /links/{code} removes the member's own link, returns 204, makes later requests for that code 404, and never reissues the freed code to a new link.

## Scope
**In:** DELETE /links/{code} for the owning member returns 204; Deleted code returns 404 on later redirect; Deleted code is never reissued to a new link; Deleting another member's link is rejected
**Out:** Editing instead of delete-and-recreate (SG-2)

## Acceptance Criteria
- **E5-S1-AC1** — *Given* a member's own link, *when* deleting it, *then* the response is 204.
- **E5-S1-AC2** — *Given* a member's own link that was just deleted, *when* requesting that code again, *then* the response is 404.
- **E5-S1-AC3** — *Given* a deleted code, *when* a new link is created, *then* the deleted code is never reissued to the new link.
- **E5-S1-AC4** — *Given* a link owned by another member, *when* the signed-in member attempts to delete it, *then* the response is 404, not 204, and the other member's link is unaffected.
